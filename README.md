# OfflineFeed

Native iPhone offline video player, iOS 16+. Imports user-authorized MP4/MOV/M4V video files. Local profile, metadata and media are held in Application Support on device, excluded from cloud backup. No social account credentials are used. The recommender mixes favorite creators, matching topics and new categories where the imported pool contains enough videos.

Version 1.1 adds a direct Wi-Fi download queue from PeerTube's public search index. Only predefined broad topic keywords are sent; no account names, passwords, private history, or raw user-entered text. The app verifies the origin's public metadata, explicit download permission, Creative Commons/public-domain license, NSFW flag and short duration before requesting the official MP4 download endpoint. It retains attribution and source links. It never attempts a forbidden download through a different endpoint. The index is an alternative source, not Instagram or TikTok; it may return too few matching videos for the five-hour target. The app stops at the actual 6 GB video budget or upon cancellation/loss of ordinary Wi-Fi. Foreground operation is recommended; iOS may suspend transfers in the background.

Build with XcodeGen and Xcode or run the GitHub Actions workflow. The resulting IPA is unsigned and must be signed for the intended iPhone before installation. The app and build source contain no personal media or account data.
