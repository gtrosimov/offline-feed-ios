# OfflineFeed

Native iPhone offline video player, iOS 16+. Imports user-authorized MP4/MOV/M4V video files. Local profile, metadata and media are held in Application Support on device, excluded from cloud backup. No social account credentials are used. The recommender mixes favorite creators, matching topics and new categories where the imported pool contains enough videos. It does not fetch social platforms' private recommendation feeds or download videos from platform pages.

Build with XcodeGen and Xcode or run the GitHub Actions workflow. The resulting IPA is unsigned and must be signed for the intended iPhone before installation. The app and build source contain no personal media or account data.
